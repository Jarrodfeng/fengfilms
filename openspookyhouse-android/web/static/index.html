Where do I get the game files?

OpenSpookyHouse is a free remake of Hugo's House of Horrors and uses the graphics from your own copy of the original game. Nothing from the original game is included in this app.

  • GOG “The Hugo Trilogy”: copy OBJECTS.DAT and SCENERY.DAT (and optionally SOUNDS.DAT) from the Hugo's House of Horrors folder to your phone.
  • Original DOS version: copy all of the .PIX and .ART files.
  • A .zip containing those files works too.

Then tap Choose game files and select them. They are stored privately inside the app, so you only need to do this once.
